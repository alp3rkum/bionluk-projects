# keykeeper (v2)
Final date: April 4th, 2024

This was my first project I took and completed on Bionluk. This application was basically an upgraded version of an already existing Python console application. I've coded an interface with Tkinter and improved its functionality.

This is a very simple password storage application that has a master password in order to enter the application, and stores passwords with keys. Each password has an identifier, and an optional description. It uses Fernet and PBKDF2HMAC algorithms to encrypt and decrypt the data.

This application was developed with Python 3.12.2.
